# Game Lab — создай космический шутер

Проба по разработке игр на Python. Ученик меняет подготовленный код, применяет изменения и испытывает игру.

## Как открыть

Готовая версия на сервере: https://31-76-227-64.sslip.io/gamelab/

Для запуска этой копии на компьютере открой терминал в общей папке «Профпробы» (на уровень выше этой папки). На компьютере, который раздаёт пробы, нужен Python 3. Выполни:

```sh
python3 -m http.server 8080
```

Открой в браузере: http://localhost:8080/gamelab/

Держи терминал открытым во время работы. Остановка сервера — Ctrl+C. Если команда python3 не найдена или используется Windows, смотри общий README в папке «Профпробы».

## Что делать ученику

1. Выполняй задания по порядку.
2. После изменения кода применяй его и проверяй поведение в игре.
3. Управление: WASD или стрелки — движение, пробел — огонь, Esc — пауза, R — новый полёт. Часть возможностей открывается по ходу заданий.

## Как начать заново

Нажми «Начать заново» и подтверди. Клавиша R перезапускает только полёт, а не всю профпробу.

Обновление страницы сохраняет прогресс текущей вкладки. Перед следующим учеником используй сброс.

Это готовая сборка сайта. Открывай её через сервер, а не двойным кликом по index.html. Файлы JS, CSS и папки с ресурсами нужны для работы; переименовывать их не надо.
